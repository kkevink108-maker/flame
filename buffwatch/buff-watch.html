Watched icon

Box the icon while the buff is active. It then measures itself for 3 s.

Alarm

When the potion is really gone, the alarm goes off in about half a second. This wait only applies while something moving (damage numbers, skill effects) is over the icon.
Fine-tuning
Set automatically when you box the icon. Lower it if you get false alarms while the buff is on; raise it if it misses that the buff is gone.
Skips the timer/stack numbers drawn over the icon's lower part.

    Tips

    • Keep this page open in its own browser window. It keeps watching while it's behind the game.
    • Don't minimize MapleStory: a minimized window sends no picture.
    • If you resize the game window or change its resolution, redo the two boxes.
    • Include the whole buff block in the area: icons shift when other buffs end.
